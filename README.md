# CSS Sidebar Navigation

A sidebar navigation interface built using HTML and CSS.

This project is part of my frontend development learning journey, where I build small projects to strengthen my understanding of web layouts, positioning, and user interface design.

## Features

- Clean sidebar layout
- Navigation menu items
- CSS styling and positioning
- Sidebar toggle functionality implemented without JavaScript
- Uses the CSS checkbox hack to control sidebar visibility

## Tech Stack

- HTML
- CSS

## Run Locally

```bash
git clone <your-repo-link>
````

Open `index.html` in your browser.

## Learning Goals

This project helped me practice:

* CSS Layouts
* CSS Positioning
* CSS Selectors
* Transitions and Animations
* UI Development
* Building interactive components using pure CSS

## Interesting Implementation Detail

Although JavaScript is commonly used to show and hide sidebars, this project achieves the toggle functionality using a combination of HTML checkboxes and CSS selectors, eliminating the need for JavaScript.
